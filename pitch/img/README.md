# Deck images

Drop a founder photo here as `headshot.jpg` (or `.jpeg` / `.png`) and
rebuild — `python3 pitch/build_pitchfest_deck.py --pdf`. The builder
picks it up automatically and crops it to the circle on slide 10; no
code change is needed.

Until a photo is present, slide 10 shows a grey placeholder disc. That
is deliberate: an obviously unfinished avatar is safer than a subtle one
you forget to replace before submitting.

The application form also requires a headshot upload separately
(JPG/JPEG/PNG), so the same file serves both.
